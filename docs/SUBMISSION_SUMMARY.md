# 파츠세이버 개발 결과 요약

파츠세이버는 누적 주행거리와 정비 이력을 결합해 차량 소모품 8종의 관리 시점과 예상 정비비를 안내하는 웹 시제품이다. 홈 대시보드, 차량 정보, 소모품 관리, 정비 이력, 유지비 리포트 화면을 구현했으며 사용자의 입력값에 따라 계산·상태 표시·지출 합계가 실제로 변경된다.

거리 기준과 기간 기준 중 먼저 도래하는 조건을 적용한다. 엔진오일·필터류·브레이크액의 정기 교체 안내와 브레이크·타이어·와이퍼·12V 배터리의 상태 점검 안내를 구분한다. 주기와 견적은 사용자가 수정할 수 있으며 모든 기본값은 시연용임을 명시했다. 전기차 선택 시 엔진오일과 흡기 필터를 관리 대상에서 제외한다.

정비일, 당시 주행거리, 교체·점검 유형, 실제 비용을 저장·수정할 수 있고, 최신 정비 기록을 반영해 다음 관리 시점을 갱신한다. 브라우저 로컬 저장으로 재실행 후 기록을 유지하며 월별·연도별 지출과 향후 정비 예산을 분리해 표시한다. 주행 상태를 수동 전환하면 상세 조회와 입력을 제한하는 UX 시연도 구현했다.

개발 산출물은 실행 가능한 단일 HTML, 전체 소스 ZIP, 실제 조작 화면을 기록한 48.1초 MP4, 주요 화면 캡처 7종, README와 테스트·공식 문서 대조 자료다. 거리/기간 계산, 월말 처리, 정비 갱신, 입력 검증, 예산 및 지출 합계에 대한 자동 테스트 12건이 통과했고, Chrome에서 실제 입력·저장·수정·새로고침 유지·주행 모드·전기차 항목 제외를 확인했다.

현재 시제품은 실제 차량·Pleos SDK·제조사 정비 DB와 연결되지 않은 웹 앱이다. 주행 상태도 실제 차량 신호가 아닌 시연용 수동 설정이다. Kotlin 기반 Android WebView 호스트 소스를 별도로 구성했으나 Android SDK 및 Gradle 부재로 APK 빌드와 Android 실행 테스트는 수행하지 않았다. 따라서 네이티브 Android 앱, Pleos 연동 완료 또는 소스+release APK 제출 요건을 충족했다고 주장하지 않는다.

후속 단계에서는 공식 Vehicle SDK의 CarInfo·Odometer 도메인과 개별 API 권한·capability를 검증한 뒤 가상 데이터 어댑터를 실제 차량 데이터 어댑터로 교체하고, 제조사 정비표 및 차량 주행 제한 요건을 적용할 계획이다.
