## 자동화된 계산 테스트

Node.js 내장 test runner, 총 12건 통과 / 실패 0건.

1. 가솔린 8종 / 전기차 엔진 부품 제외 후 6종.
2. 엔진오일 44,200 km에서 800 km 남음(임박), 45,200 km에서 200 km 초과.
3. 거리 여유가 있어도 기간 도달 시 기준 도달 상태.
4. 1월 31일 + 1개월의 월말 처리와 윤년 2월 29일 처리.
5. 교체 저장 후 다음 55,200 km / 2027-11-15. 동일 ID 수정 시 중복 추가 없음.
6. 엔진오일 단순 점검은 교체 주기를 초기화하지 않음.
7. 타이어 점검은 다음 상태 점검 기준을 갱신.
8. 음수 비용·미래 날짜·현재 거리 초과·존재하지 않는 날짜 거부.
9. 기존 기록과 날짜/주행거리 순서가 모순되는 기록 거부.
10. 기간만/거리만 적용하는 주기 지원.
11. 예상 교체 예산 165,000원, 2026 지출 143,000원, 3/4/5월 합계와 다른 연도 0원.
12. 입력 순서와 무관하게 가장 최근 정비 이력 사용.
